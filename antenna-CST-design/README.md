# TACTIBAND Antenna CST Design

## Overview

This folder contains the CST-based antenna design and simulation results
developed by Team PHONEX for the TACTIBAND project.

The antenna design is intended for integration with the proposed
helmet-mounted conformal antenna architecture.

## Antenna Design

The antenna geometry consists of slot-loaded radiating elements with defined
feed locations and a supporting structure.

The design is used as the geometry reference for electromagnetic simulation
and further optimization.

## CST Simulation Workflow

The antenna design follows this simulation workflow:

```text
Antenna Geometry
        ↓
Material Definition
        ↓
Boundary Conditions

Mesh Generation
        ↓
Parameter Sweep
        ↓
S-Parameter Analysis
        ↓

        ↓

# TACTIBAND Antenna CST Design

## Overview

This folder contains the antenna CAD and CST design reference developed by
Team PHONEX for the TACTIBAND helmet-mounted conformal antenna architecture.

The design focuses on a low-profile antenna structure intended for integration
with the helmet surface and further electromagnetic simulation.

## Antenna Structure

The design consists of radiating elements with slot-loaded geometry arranged
on a supporting dielectric structure.

The CAD representation is used as the geometry reference for electromagnetic
simulation and further antenna optimization.

## Design Features

- Slot-loaded radiating elements
- Dual-element antenna arrangement
- Defined feed locations
- Supporting dielectric structure
- Conductive surrounding structure
- Low-profile antenna configuration
- Geometry suitable for CST electromagnetic analysis

## TACTIBAND Integration

The antenna design is intended to be integrated with the TACTIBAND helmet
architecture.

The overall architecture includes:

- CDIMPA conformal antenna elements
- Helmet-conformal placement
- AMC/RF shielding layer
- Ruggedized coaxial interface
- UHF + L-band communication support
